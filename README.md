## Characteristics of Spring Boot

- Dependency Injection
- Model View Controller (MVC)
- API RESTful
- Reactive Programming WebFlux
- Aspect Oriented Programming (AOP)
- Zero Configuration
- Spring Security JWT
- Spring Data JPA, Validation, Security, JUnit5, Microservices, Cloud

## Other contents in this course

- Deploy in AWS EC2
- Angular and React
- Thymeleaf
- Export to PDF and XLS
- Functional Programming and Reactive with Reactor
- Spring Data Mongo
- File Upload
- Bootstrap
