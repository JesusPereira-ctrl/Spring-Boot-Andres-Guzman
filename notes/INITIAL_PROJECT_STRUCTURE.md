# Initial Project Structure

```text
mi-api/
├── .mvn/ -> Maven Wrapper configuration
|
├── src/ -> source code
│   ├── main/
│   │   ├── java/com/ejemplo/miapi -> base package (main project code)
│   │   │   ├── MiApiApplication.java
│   │   │   ├── controller/
│   │   │   │   └── TareaController.java
│   │   │   ├── service/
│   │   │   │   └── TareaService.java
│   │   │   ├── repository/
│   │   │   │   └── TareaRepository.java
│   │   │   └── model/
│   │   │       └── Tarea.java
│   │   └── resources/ -> configuration, static files and templates
│   │       └── application.yml
│   └── test/ -> tests with JUnit and Mockito
│       └── java/com/ejemplo/miapi
│           └── MiApiApplicationTests.java
|
├── target/ -> build output (generated, not committed): classes, reports and the .jar
├── .gitignore -> files and folders Git should ignore
├── HELP.md -> reference documentation links generated by Spring Initializr
├── mvnw -> Maven Wrapper for Linux/macOS (Gradle uses gradlew)
├── mvnw.cmd -> Maven Wrapper for Windows (Gradle uses gradlew.bat)
└── pom.xml -> Maven config: dependencies and build
```
